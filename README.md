# Direct Settlement and Vehicle Currency Persistence

This repository contains the computational replication files for the manuscript
“Direct Settlement and Vehicle Currency Persistence: A Dual-Structure Mechanism.”

The current version implements the revised settlement-choice model used in the
manuscript. The model is technology-generic: it studies a vehicle route and a
direct bilateral settlement route, rather than a specific currency pair or a
specific technology such as AI.

## Model summary

Trading relationships choose direct settlement when

```text
S_dir(t) + F(t) / A_i < S_USD,
```

with

```text
S_dir(t) = max{S_theory(t), S_floor}
S_theory(t) = alpha / V_eff(t)^delta + S_base * (1 - eta * z(t))
V_eff(t) = V_dir(t-1) + V_seed
S_floor = kappa * S_USD
```

The steady-state adoption threshold is

```text
A* = F_inf / [(1 - kappa) S_USD].
```

The analytical model determines the long-run sorting threshold. The computational
model traces the transition generated by lagged direct-market depth.

## Repository structure

- `src/model.py` — core computational model and baseline validation.
- `src/fig1.py` — Figure 1: baseline transition.
- `src/fig2.py` — Figure 2: analytical threshold and simulated sorting.
- `src/fig3.py` — Figure 3: endogenous-depth versus fixed-depth counterfactual.
- `src/fig4.py` — Figure 4: variable-cost-only versus both cost channels.
- `src/fig5.py` — Figure 5: long-run comparative statics in `kappa` and `F_inf`.
- `src/figC1.py` — Online Appendix Figure C1: seed-liquidity transition robustness.
- `src/figC2.py` — Online Appendix Figure C2: Pareto-shape robustness.
- `src/run_all_figures.py` — regenerates all main and supplementary figures.
- `src/validate_results.py` — checks the numerical targets reported in the manuscript.
- `EXPECTED_RESULTS.md` — benchmark values used for verification.
- `requirements.txt` — tested Python dependencies.

No external empirical or proprietary data are required.

## Environment

The current files were tested with:

- Python 3.13.5
- NumPy 2.3.5
- pandas 2.2.3
- Matplotlib 3.10.8

Install dependencies from the repository root:

```bash
python -m pip install -r requirements.txt
```

## Reproduction

From the repository root, run:

```bash
python src/validate_results.py
python src/run_all_figures.py
```

The first command checks the benchmark values used in the manuscript. The second
regenerates Figures 1–5 and Online Appendix Figures C1–C2 in PDF, EPS, and
high-resolution PNG format, together with the corresponding CSV outputs.

The random seed is fixed at 123. Relationship sizes are drawn once for a simulation
and held fixed through time. Counterfactual comparisons that require the same
cross-section reuse the same size draw.

## Main benchmark

The baseline parameterization implies:

- replication/hedging floor: `S_floor = 0.006`;
- analytical threshold: `A* = 6.25`;
- first direct adoption: period 63;
- direct spread first reaches the floor: period 66;
- long-run direct-settlement value share: approximately `0.795876`;
- long-run direct-settlement count share: `0.425`;
- largest long-run vehicle-route relationship: approximately `6.232221`;
- smallest long-run direct-settlement relationship: approximately `6.293612`.

Long-run statistics are averages over the final 30 periods of a 150-period run.

## Data and reproducibility statement

All numerical results are generated by the model itself. No external empirical or
proprietary data are used. The source files use a fixed pseudo-random seed so that
the reported benchmark results and figures can be reproduced exactly.
